# חתימה דיגיטלית (Ogen Sign)

אפליקציית ווב לחתימה דיגיטלית על קבצי PDF — **ללא שרת אפליקציה**: כל הלוגיקה רצה
בדפדפן, והמסמכים נשמרים באחסון מאובטח של Supabase כדי שקישורי החתימה יעבדו מכל
מכשיר. הממשק בעברית (RTL) עם אפשרות מעבר לאנגלית.

## יכולות

- **העלאת מסמכים** — PDF או Word (מומר ל-PDF בדפדפן); כמה קבצים מאוחדים למסמך אחד
- **עורך שדות** — מיקום שדות בגרירה/שינוי גודל (מגע ועכבר):
  - ✒️ **חתימה** — לוח ציור עם חיתוך רקע אוטומטי (או הקלדה)
  - 🪪 שם פרטי / שם משפחה / שם מלא / 🆔 תעודת זהות — ממולאים פעם אחת ומופצים לכל השדות התואמים
  - 🔤 **טקסט** / ❓ **שאלה** — תמיכה מלאה בעברית (RTL)
  - 📅 **תאריך**, ☑️ **תיבת סימון**, 🔡 **ראשי תיבות**
- **קישור חתימה חד-פעמי** — שולחים לינק, החותם ממלא וחותם מהנייד או מהמחשב
- **סבב חתימות** — עד 2 חותמים בזה אחר זה על אותו קישור
- **תבניות עם לינק קבוע** — כל מי שנכנס ללינק חותם על עותק חדש; כל חתימה נשמרת בנפרד
- **לוח מסמכים** — מעקב סטטוס, הורדת מסמכים חתומים, ייצוא Excel/CSV, הורדה מרוכזת
- **התראות** — במייל (דרך Make.com) ו/או בטלגרם, כולל המסמך החתום עצמו
- **אזור בעלים מוגן** — מסך כניסה לפני אזור הניהול

## טכנולוגיה

- **React + Vite**
- **pdf.js** לרינדור עמודי ה-PDF (worker מקומי, ללא CDN)
- **pdf-lib** ליצירת ה-PDF החתום
- **Supabase** (Postgres + Storage) לשמירת בקשות חתימה, תבניות והקבצים
- **mammoth + html2canvas + jsPDF** להמרת Word ל-PDF בדפדפן

### למה טקסט עברי מרונדר כתמונה?

הפונטים המובנים של `pdf-lib` תומכים רק ב-WinAnsi ולא בעברית. לכן טקסט ותאריך
מצוירים על `canvas` ומוטבעים כ-PNG שקוף — כך כל תו Unicode עובד, כולל עברית
בכיוון RTL.

## חיבור לבוט טלגרם 🤖

אפשר לקבל התראות — כולל קובץ ה-PDF החתום — ישירות לטלגרם:

1. פתחו בטלגרם שיחה עם **@BotFather** ושלחו `/newbot` כדי ליצור בוט. תקבלו **טוקן**.
2. שלחו לבוט החדש שלכם הודעה כלשהי (למשל `/start`).
3. באפליקציה: **הגדרות ← בוט טלגרם** — הדביקו את הטוקן ולחצו **"מצא Chat ID"**
   (מזהה את הצ'אט אוטומטית). אפשר ללחוץ **"שלח הודעת בדיקה"** לאימות.
4. שמרו. מעכשיו כל בקשת חתימה חדשה תשלח לטלגרם:
   - ✉️ הודעה כשנוצר קישור חתימה / כשהמסמך עובר לחותם הבא
   - ✅ הודעה + **המסמך החתום כקובץ** כשהחתימה הושלמה

ההתראה נשלחת ישירות מהדפדפן ל-Telegram Bot API — בלי שרת ובלי תלות ב-Make
(אפשר לחבר גם וגם; כל ערוץ עובד בנפרד).

> **אבטחה:** הטוקן מוטמע בבקשות החתימה כדי שדפדפן החותם יוכל לשלוח את
> ההתראה. השתמשו בבוט ייעודי להתראות בלבד, לא בבוט שיש לו הרשאות אחרות.

## הרצה מקומית

```bash
npm install
npm run dev      # פיתוח
npm run build    # בנייה לפרודקשן (תיקיית dist/)
npm run preview  # תצוגה מקדימה של ה-build
```

לבדיקה מקומית מקצה לקצה **ללא רשת וללא Supabase** — פתחו את האפליקציה עם
`?mock=1` בכתובת: במצב הזה הכול נשמר ב-localStorage של הדפדפן.

https://ogennursing-ux.github.io/-/
