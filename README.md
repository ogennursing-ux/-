# חתימה דיגיטלית (Ogen Sign)

אפליקציית ווב לחתימה דיגיטלית על קבצי PDF — **רצה כולה בדפדפן**, ללא שרת.
הקובץ לעולם לא עוזב את המכשיר של המשתמש.

## יכולות

- העלאת PDF בגרירה או בחירה מהמחשב
- צפייה בכל עמודי המסמך
- הוספת שדות על המסמך ומיקומם בגרירה/שינוי גודל (מגע ועכבר):
  - ✒️ **חתימה** — לוח ציור עם חיתוך רקע אוטומטי
  - 🔤 **טקסט** — תמיכה מלאה בעברית (RTL)
  - 📅 **תאריך**
  - ☑️ **תיבת סימון**
- הורדת PDF חתום חדש בלחיצה אחת

## טכנולוגיה

- **React + Vite**
- **pdf.js** לרינדור עמודי ה-PDF (worker מקומי, ללא CDN)
- **pdf-lib** ליצירת ה-PDF החתום

### למה טקסט עברי מרונדר כתמונה?

הפונטים המובנים של `pdf-lib` תומכים רק ב-WinAnsi ולא בעברית. לכן טקסט ותאריך
מצוירים על `canvas` ומוטבעים כ-PNG שקוף — כך כל תו Unicode עובד, כולל עברית
בכיוון RTL.

## חיבור לבוט טלגרם 🤖

אפשר לקבל התראות — כולל קובץ ה-PDF החתום — ישירות לטלגרם:

1. פתחו בטלגרם שיחה עם **@BotFather** ושלחו `/newbot` כדי ליצור בוט. תקבלו **טוקן**.
2. שלחו לבוט החדש שלכם הודעה כלשהי (למשל `/start`).
3. באפליקציה: **הגדרות ← בוט טלגרם** — הדביקו את הטוקן ולחצו **"מצא Chat ID"**
   (מזהה את הצ'אט אוטומטית). אפשר ללחוץ **"שלח הודעת בדיקה"** לאימות.
4. שמרו. מעכשיו כל בקשת חתימה חדשה תשלח לטלגרם:
   - ✉️ הודעה כשנוצר קישור חתימה / כשהמסמך עובר לחותם הבא
   - ✅ הודעה + **המסמך החתום כקובץ** כשהחתימה הושלמה

ההתראה נשלחת ישירות מהדפדפן ל-Telegram Bot API — בלי שרת ובלי תלות ב-Make
(אפשר לחבר גם וגם; כל ערוץ עובד בנפרד).

> **אבטחה:** הטוקן מוטמע בבקשות החתימה כדי שדפדפן החותם יוכל לשלוח את
> ההתראה. השתמשו בבוט ייעודי להתראות בלבד, לא בבוט שיש לו הרשאות אחרות.

## הרצה מקומית

```bash
npm install
npm run dev      # פיתוח
npm run build    # בנייה לפרודקשן (תיקיית dist/)
npm run preview  # תצוגה מקדימה של ה-build
```

## פריסה

`vite.config.js` מוגדר עם `base: './'` כך שה-build עובד גם משורש דומיין וגם
מתת-נתיב (למשל GitHub Pages).
